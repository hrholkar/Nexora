## 1. Project Overview

NEXORA is a genuine academic LLM development and experimentation platform. It enables engineers, researchers, and students to discover pretrained open-source models, upload and preprocess datasets, perform authentic Low-Rank Adaptation (LoRA) fine-tuning on local consumer hardware (CPU with 16GB RAM), interact with adapted models, conduct side-by-side comparative inference, evaluate empirical metrics (Perplexity, ROUGE, BLEU, Token F1), and compile publication-grade technical reports.

> **CRITICAL ARCHITECTURAL GUARANTEE:**  
> NEXORA does not simulate fine-tuning, mock inference, or display fabricated responses. Every inference token is generated by loaded neural network weights, and every training loss step is computed via PyTorch backpropagation.

## 4. Hardware Optimization & CPU Configuration

The local ML engine automatically inspects host resources (`psutil`, `torch.cuda.is_available()`) and adapts:
- **Compute Precision:** FP32 on CPU (or FP16 if CUDA is present).
- **Batch Size:** `1` (prevents RAM spikes and out-of-memory errors).
- **Gradient Accumulation:** `4` steps (simulates an effective batch size of 4).
- **Sequence Length:** Capped at `256` or `128` tokens for CPU safety.
- **LoRA Configuration:** `r = 8`, `alpha = 16`, `dropout = 0.05` targeting attention projections (`q_proj`, `v_proj`, `c_attn`).

### Curated Pretrained Models
1. **HuggingFaceTB/SmolLM2-360M-Instruct** *(Recommended Initial Model)*: 360M parameters, Llama architecture, excellent for instruction following on 16GB RAM.
2. **distilbert/distilgpt2**: 82M parameters, ultra-lightweight, rapid prototyping and unit testing.
3. **Qwen/Qwen2.5-0.5B-Instruct**: 490M parameters, state-of-the-art reasoning and coding.
4. **TinyLlama/TinyLlama-1.1B-Chat-v1.0**: 1.1B parameters, balanced chat capability.

## 7. Local Setup & Execution (Windows PowerShell)

### Prerequisites
- Python 3.10+ (tested on Python 3.12 / 3.13)
- Node.js v18+ & npm
- Git

### Quick Start (One-Click)
Run the automated launcher:
```powershell
.\start-local.ps1
```

### Manual Step-by-Step Setup

#### 1. Backend & ML Environment Setup
```powershell
# Navigate to repository root
cd C:\Users\hrhol\.gemini\antigravity\scratch\Nexora

# Activate virtual environment
.\.venv\Scripts\Activate.ps1

# Install requirements (if not already installed)
pip install -r requirements-ml.txt

# Start FastAPI backend server
$env:PYTHONPATH="."
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```
Backend will be live at `http://localhost:8000` (API docs at `http://localhost:8000/docs`).

#### 2. Frontend Setup
Open a new PowerShell terminal:
```powershell
cd C:\Users\hrhol\.gemini\antigravity\scratch\Nexora\frontend

# Install dependencies (if needed)
npm install

# Start Vite dev server
npm run dev
```
Frontend will be live at `http://localhost:5173`.

## 8. Fine-Tuning Instructions

1. Open **Dataset Studio** in the UI:
   - Click **"Load Sample Datasets"** to seed `Academic-Reasoning-Sample` or `LLM-Engineering-Sample`, or upload your custom `.jsonl` / `.json` / `.csv` file.
   - Run **Format Validation** to verify schema.
   - Click **"Generate & Save Train/Val Splits"** (80% Train / 20% Val).
2. Open **Fine-Tuning Studio**:
   - Choose `HuggingFaceTB/SmolLM2-360M-Instruct` or `distilbert/distilgpt2`.
   - Select your prepared training dataset.
   - Use default CPU hyperparameters:
     - `Epochs: 1`
     - `Learning Rate: 0.0003`
     - `Batch Size: 1`
     - `Gradient Accumulation: 4`
     - `Max Seq Length: 256`
     - `LoRA Rank (r): 8`
     - `LoRA Alpha: 16`
   - Click **"Start LoRA Fine-Tuning"**.
3. Observe live step loss trajectory, CPU usage, and elapsed time on the interactive Recharts curve.
4. Upon completion, the adapter is automatically saved to `storage/adapters/<experiment_id>/`.
5. Open **LLM Playground** or **Model Comparison** to interact with the adapted model.
6. Open **Reports** to download the formal publication PDF report.

## 10. Free Render Deployment Guide

NEXORA includes declarative deployment configuration in `render.yaml`.

### Steps to Deploy for Free:
1. Push repository code to GitHub: `https://github.com/hrholkar/Nexora`.
2. Log into [Render Dashboard](https://dashboard.render.com/) (Free account).
3. Click **"New"** → **"Blueprint"**.
4. Connect the GitHub repository `hrholkar/Nexora`.
5. Render will detect `render.yaml` and configure two free services:
   - **`nexora-backend`**: Free Web Service (Python, `pip install -r requirements.txt`, start command `uvicorn backend.app.main:app`).
   - **`nexora-frontend`**: Free Static Site (Publish directory `frontend/dist`, rewrite rule `/* -> /index.html`).
6. Click **"Apply"**.
7. Once deployed:
   - Frontend live URL: `https://nexora-frontend.onrender.com` (or your assigned subdomain).
   - Backend live URL: `https://nexora-backend.onrender.com`.

*(Note: In Render Free mode, `ML_ENGINE_ENABLED=false` ensures the cloud backend remains lightweight (512MB RAM safe) while all UI catalogs and metadata remain publicly accessible).*

## 11. Known Limitations & Academic Considerations

1. **CPU Execution Speed:** Fine-tuning on CPU with FP32 is computationally slower than high-end NVIDIA GPUs. LoRA and compact models (`360M` to `490M`) make CPU training feasible without memory crashes.
2. **Automatic Evaluation Metrics:** Metrics like ROUGE and BLEU evaluate lexical n-gram overlap against ground truth; for open-ended reasoning, evaluate outputs qualitatively in the Side-by-Side Comparison view.
3. **Render Free Sleep Cycle:** Render free web services spin down after 15 minutes of inactivity; initial wakeup may take ~30-45 seconds.
